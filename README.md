# 🐾 Hierarchical Clustering for Animal Class Prediction

This project demonstrates **unsupervised learning** using **hierarchical clustering** to classify animals into groups based on their features and characteristics. It highlights how clustering can reveal natural groupings in biological data without prior labels.

---

## 🚀 Features
- Applied **Agglomerative Hierarchical Clustering**  
- Visualized clusters using **dendrograms**  
- Grouped animals into classes based on attributes  
- Explored similarities and dissimilarities in animal features  
- Demonstrated unsupervised learning workflow with real-world biological data
